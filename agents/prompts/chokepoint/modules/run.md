# The run

A run repeats: a build phase (place towers and augments, spend gold, a countdown), a wave walking the road, then a draft, until the lives run out. Gold comes from kills, cleared waves and starting a wave early; it buys tower slots and rerolls.

## The bar for a new rule or action
- **A real choice.** Not the mirror or the inverse of something that exists (sending early sells seconds for gold, so buying seconds back adds nothing), and with stakes bigger than a few gold or a few seconds.
- **The player would miss it.** If most players would never use it, or would always use it the same way, it is not a choice.
- **It keeps the run's game.** Nothing that skips the defending the run is about.

## Not in this game
The owner removed these. Don't propose them again, or anything that works the same way.
- A panic pulse (T0063): 25 gold once per wave, and every enemy on the board vanished.
- "Stay put" (T0206): 5 gold for 3 more build seconds, once per build phase. The mirror of sending early, and too small a choice to be worth a button.
